# Первичный анализ качества данных

## 1. Общая информация

Для проекта использован датасет Online Retail.

Исходный набор данных содержит:
- Количество строк: **541 909**
- Количество столбцов: **8**

## 2. Типы данных

- `InvoiceDate` — дата и время.
- `Quantity` — целочисленный тип.
- `UnitPrice` — числовой тип.
- `CustomerID` — тип `float64`; требуется дополнительная обработка перед использованием в качестве идентификатора клиента.

## 3. Обнаруженные проблемы качества данных

| Проверка | Результат |
|---|---:|
| Пропуски CustomerID | 135 080 |
| Пропуски Description | 1 454 |
| Строки с InvoiceNo, начинающимся на C | 9 288 |
| Уникальные счета с префиксом C | 3 836 |
| Отрицательное Quantity | 10 624 |
| Нулевое Quantity | 0 |
| Нулевая или отрицательная UnitPrice | 2 517 |

## 4. Выводы первичного анализа

В исходном наборе данных обнаружены:
- Пропущенные идентификаторы клиентов.
- Отсутствующие описания товаров.
- Отменённые заказы, обозначенные префиксом C в InvoiceNo.
- Отрицательные значения количества товаров.
- Нулевые и отрицательные цены.

Эти особенности требуют дополнительной проверки и обработки перед проведением аналитики.

## 5. Следующий этап

На следующем этапе выполнена очистка данных с использованием Python и pandas. Цель обработки — подготовить набор данных для загрузки в PostgreSQL и последующего анализа продаж.
