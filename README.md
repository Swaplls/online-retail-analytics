# Online Retail — проект по анализу продаж

## О проекте

Учебный аналитический проект на основе датасета Online Retail. Цель — провести анализ транзакций интернет-магазина, изучить динамику продаж, поведение клиентов и наиболее популярные товары.

Проект демонстрирует полный цикл работы аналитика: от подготовки данных до анализа в SQL и визуализации результатов в Power BI.

## Используемые технологии

- **Python:** pandas, numpy, matplotlib, seaborn
- **SQL:** PostgreSQL
- **BI:** Power BI
- **Среда разработки:** Jupyter Notebook, pgAdmin 4

## Структура проекта

- `01_data_quality_analysis.ipynb` — исследование и очистка данных в Python.
- `analytics_queries.sql` — аналитические запросы PostgreSQL.
- `transaction_analytics.pbix` — интерактивный дашборд Power BI.
- `data_quality_notes.md` — результаты первичного анализа качества данных.
- `jupyter_analysis_screenshots.docx` — скриншоты анализа в Jupyter Notebook.
- `.gitignore` — список исключённых из Git файлов.

Исходный и очищенный датасеты хранятся локально и не загружены в репозиторий из-за размера файлов.

## Выполненные этапы

1. Исследование исходного набора данных.
2. Очистка данных: обработка пропусков, дубликатов и некорректных значений.
3. Подготовка данных с помощью Python и pandas.
4. Загрузка данных в PostgreSQL.
5. Создание аналитических SQL-запросов с использованием JOIN, CTE, агрегатных функций и оконных функций.
6. Анализ динамики продаж, повторных покупок и товарной структуры.
7. Создание интерактивного дашборда в Power BI.

## Основные результаты

- Обработано **536 641 транзакционная запись**.
- Выявлено **4 070 клиентов**.
- Проанализирована динамика продаж за период с декабря 2010 по декабрь 2011 года.
- Рассчитана средняя сумма заказа — **533,17**.
- Доля клиентов с повторными покупками — **65,59%**.
- Определены страны и товары с наибольшими объёмами продаж.

## SQL-навыки

В проекте использованы:

- JOIN и GROUP BY;
- агрегатные функции;
- CTE и подзапросы;
- HAVING;
- оконные функции LAG(), ROW_NUMBER(), RANK();
- анализ повторных покупок;
- сравнение продаж между месяцами.

## Дашборд

Интерактивный дашборд создан в Power BI. Он позволяет изучать ключевые показатели продаж, динамику по месяцам и распределение продаж по странам.

## Источник данных

UCI Machine Learning Repository — Online Retail Dataset.

## Бизнес-выводы
По результатам нашего анализа можно выделить следующие наблюдения:
1. Основной рынок — Великобритания. На неё приходится около 6,75 млн денежных единиц продаж. Это крупнейший рынок интернет-магазина.
2. Высокая доля повторных клиентов. Около 65,59% клиентов совершали повторные покупки. Это говорит о значительной роли удержания покупателей.
3. Средний чек составляет 533,17. Этот показатель можно использовать как базовый ориентир для оценки изменений покупательского поведения.
4. Отмены существенно влияют на финансовый результат. Сумма отмен составляет около 894 тыс. при объёме продаж 10,64 млн — примерно 8,4% от суммы продаж.
5. Продажи имеют выраженную сезонность. На графике заметен рост к ноябрю 2011 года. Декабрь нельзя напрямую сравнивать с полными месяцами: данные заканчиваются 9 декабря.
